# Scientific Research AI - Development Roadmap

## Project Objective

Build an AI-powered scientific research analytics
platform using Big Data, Knowledge Graphs and GraphRAG.

## Development Phases

- [ ] Phase 1: Project setup and GitHub repository
- [ ] Phase 2: Scientific data collection with Crawler scrapy
- [ ] Phase 3: Big Data processing with HDFS and Spark
- [ ] Phase 4: Knowledge Graph construction with Neo4j
- [ ] Phase 5: Graph Analytics with Cypher
- [ ] Phase 6: GraphRAG assistant development
- [ ] Phase 7: Benchmarking and performance evaluation
- [ ] Phase 8: Interactive dashboard and final presentation

## Main Technologies

- Python
- Apache Hadoop HDFS
- Apache Spark
- Neo4j
- Large Language Models (LLMs)
- GraphRAG
- Streamlit

## Current Status

Project initialization.
